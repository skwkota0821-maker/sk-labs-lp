# SK LABS Harness 会員制Web統合設計

作成日：2026年8月22日

## 目的

WebをSK LABS Harnessの中核チャネルとして位置づけ、X・Instagram・LINE・note・メール・Stripe・Google Drive・n8nを共通の顧客ID、CRM、イベント、コンテンツ、売上データで接続する。

## 会員制Webの役割

- SK LABS所有のファーストパーティ顧客基盤
- ログイン後の会員ポータル
- 購入履歴・契約状態・配布物・限定記事の集約
- X / Instagram / LINE / note / メールの接点統合
- Stripe購入情報との紐付け
- UTM・流入元・コンバージョンの保持
- 会員ごとのタグ、権限、スコア、行動履歴の管理
- AI / MCP / n8nから操作できる共通APIの入口

### 会員ランク

初期実装では複雑化を避け、次の3段階を推奨する。

1. 無料会員
2. 有料会員
3. 購入商品別アクセス権

会員ランクと商品アクセス権を分離し、後からCreator、Publishing、マンガ、教材、コミュニティ等を追加できる構造にする。

## 顧客ID設計

内部のSK LABS会員IDを正本とし、外部サービスIDを従属させる。

- sk_member_id
- email
- stripe_customer_id
- x_user_id
- instagram_user_id
- line_user_id
- note_user_id または取得可能な識別子

外部サービスIDを主キーにしない。

## 成人向け外部リンク領域

成人向け領域は通常事業から論理分離し、SK LABS側では成人向けコンテンツ本体の配信・保管・決済を行わず、条件を満たした会員に外部サービスへの導線のみを表示する。

### アクセス条件

- 会員ログイン済みであること
- 18歳以上であることを確認済みであること
- 成人向け領域に関する注意事項・利用条件へ同意済みであること
- `adult_access` 権限が有効であること

### 権限設計

通常会員権限と成人向けアクセス権限を分離する。

- `adult_verified_at`：18歳以上確認日時
- `adult_terms_accepted_at`：成人向け領域の利用条件同意日時
- `adult_access`：成人向け外部リンク領域の表示可否

成人向けアクセス権限をStripeの購入状態や通常の有料会員ランクと自動的に同一視しない。

### 表示方針

- 通常のトップページ、商品一覧、検索結果へ露骨な成人向け画像・動画を表示しない
- 成人向け導線は専用ページ内に限定する
- 外部リンクであることを明示する
- 外部サービスの利用規約、決済、購入、視聴、配信は当該外部サービス側で完結させる
- SK LABS側で成人向け決済情報を処理しない
- リンク先の合法性、年齢制限、規約適合性を登録・更新時に確認する運用を設ける

### 禁止対象

- 未成年者を性的に扱う内容またはその疑いがある内容
- 実在人物の同意のない性的コンテンツ
- 違法コンテンツ
- 権利侵害コンテンツ
- 年齢・同意・権利関係を確認できない外部リンク

### イベント

- `adult.age_verified`
- `adult.terms_accepted`
- `adult.access_granted`
- `adult.access_revoked`
- `adult.external_link_viewed`
- `adult.external_link_clicked`

成人向け領域のイベントは分析用途で通常イベント基盤へ送るが、通常コンテンツの閲覧履歴とは画面上で分離して扱う。

### 外部リンク管理

外部リンクはコードへ直書きせず、管理対象として保持する。

- 表示名
- 遷移先URL
- 対象カテゴリ
- 有効 / 無効
- 成人向け指定
- 登録日
- 最終確認日
- 利用規約確認状態
- 管理メモ

無効化したリンクは即時に会員画面から非表示にできる構造にする。

## セキュリティ原則

- 認証情報をGitHubへ保存しない
- 秘密情報は環境変数 / Secret Storeへ置く
- 決済情報をSK LABS側で直接保持しない
- Stripe Webhookは署名検証する
- 会員権限判定はサーバー側で行う
- 管理者操作は監査ログへ残す
- 外部ID連携は本人確認済みフローを通す
- 退会とデータ削除の導線を用意する
- 成人向け領域は通常会員領域と権限・表示・監査ログを分離する
- 成人向け外部リンクは有効性と規約適合性を定期確認できる状態にする

## 方針

Webは単なるLPではなく、SK LABSが所有する顧客・販売・コンテンツの中核資産とする。

SNSは集客チャネル、Webは顧客資産の正本、Stripeは通常事業の決済正本、Google Driveは制作資産の正本、n8nは自動化オーケストレーターとして役割を分離する。

成人向け領域はHarness Coreの会員IDとイベント基盤のみ共有し、通常事業の決済・表示・権限とは分離する。SK LABS会員Webでは成人向けコンテンツ本体を保管・配信せず、18歳以上確認済み会員に対する外部サービスへの導線として実装する。
